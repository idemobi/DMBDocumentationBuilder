# DMBExampleToRaw Troubleshooting

## Project-specific section

When copying this file to another PageBuilder ecosystem project, update this section first.

- Project name: `DMBExampleToRaw`
- Project root folder: `DMBDocumentationBuilder/Source/ExampleToRaw`
- Main role: reusable raw example generation package.

## Known issues

### Source directory not found

Check `DMBExampleToRawOptions.SourceDirectoryPath`.

The package does not resolve repository-relative paths. The orchestrator must pass a valid absolute or process-relative path.

### No raw files are generated

Check `SourceSearchPattern` and confirm source files exist below `SourceDirectoryPath`.

The default pattern is `*.cshtml`.

### Generated Razor renders instead of displaying source

Check that the raw file was generated by the package and that Razor `@` characters were escaped as `@@`.

### Displayed code has unexpected HTML output

Confirm `RawCodePrefix` and `RawCodeSuffix` are valid for the host website.

The default wrapper targets the current DMB demo code block markup.

### Raw target directory contains stale files

Keep `CleanTargetDirectory` set to `true` unless the orchestrator intentionally merges generated files with existing files.
